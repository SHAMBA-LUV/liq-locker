Every function below is generated from the ABI of the deployed bytecode. Reads run over a public RPC — no wallet, no consent needed. Writes arm only after you connect.

reads work without one

read — public, free, instant

Zero-argument constants are read on load. locks_of is an eth_call-only view — never call it from a contract.

approve — the step before any lock

lock_* pulls tokens via transferFrom, so the token (the LUV/WETH pair, prefilled) must approve the locker first. This is the only call on this page that goes to the token instead of the locker.

wallet-gated

write — beneficiary-bound, extend-only, no owner

Anyone may lock_* and sweep_surplus; only a lock's beneficiary may extend, assign, withdraw, or collect it. Nothing here — or anywhere — shortens a lock or pauses the contract. Amounts and durations are raw units: wei for tokens, seconds for time, blocks for the block gate.
